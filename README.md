# Naruto Fandom Scraper

This project contains tools for scraping and extracting character data from the Naruto Fandom Wiki.

## Description

The project consists of Python scripts designed to:
1.  **Scrape Character List**: Fetch a comprehensive list of characters from the Naruto Fandom Wiki, including their names, profile links, and thumbnail image URLs.
2.  **Extract Character Details**: Visit each character's profile page to (potentially) extract more detailed information.

## Getting Started

### Dependencies

-   Python 3.9+
-   `requests`
-   `beautifulsoup4`
-   `pandas`

You can install the required dependencies using pip:

```bash
pip install -r requirements.txt
```

### Structure

The project structure is as follows:

-   `src/`: Contains the source code for the scrapers.
    -   `naruto_scraper.py`: The main script to scrape the list of characters and save them to `characters.json`.
    -   `link_extractor.py`: A script to process the `characters.json` file and visit each character's page.
-   `characters.json`: The output file generated by `naruto_scraper.py` containing character data.
-   `requirements.txt`: List of Python dependencies.
-   `Naruto Fandom Scraper Final.ipynb`: Legacy Jupyter Notebook version of the scraper.
-   `link_extracter_from_json.ipynb`: Legacy Jupyter Notebook version of the link extractor.

### Executing program

#### 1. Scrape Character List

To scrape the list of characters and generate `characters.json`, run:

```bash
python src/naruto_scraper.py
```

This will fetch character data from multiple category pages and save it to `characters.json`.

#### 2. Extract Character Details

To visit character pages (currently set to process just one for demonstration), run:

```bash
python src/link_extractor.py
```

This script reads from `characters.json` and visits the links provided. You can modify the `limit` parameter in the `main` block of `src/link_extractor.py` to process more characters.
